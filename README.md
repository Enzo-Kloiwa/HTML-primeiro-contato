# 🧠 Quiz Interativo de Programação

Página web e hub de quizzes interativos desenvolvidos em **HTML5 semântico**, focando em boas práticas de estruturação web, ampla variedade de elementos de formulário nativos e navegação hipertextual integrada entre módulos e links direcionados.

---

## 🎯 Sobre o Projeto

O projeto consolida os fundamentos de desenvolvimento web front-end sem a dependência inicial de frameworks ou bibliotecas externas. Ele apresenta um quiz completo sobre linguagens e conceitos de programação, além de contar com direcionamentos interativos, navegação entre páginas secundárias e envio de dados via formulários.

### ✨ Funcionalidades Principais

* **HTML5 Semântico:** Estrutura legível e acessível utilizando tags como `<header>`, `<main>`, `<section>`, `<figure>`, `<figcaption>`, `<fieldset>`, `<details>` e `<footer>`.
* **Múltiplos Formatos de Input:**
  * Seleção única (`radio`) e múltipla (`checkbox`).
  * Entradas de texto livre (`text`), máscara de segurança (`password`) e seletor nativo de calendário (`date`).
  * Envio de anexos (`file`) e seleção suspensa (`select`/`option`).
* **Navegação Hipertextual:**
  * Integração com páginas complementares (`OutrosQuizzes.html`).
  * Direcionamento por pontos específicos, parâmetros e referências externas.
* **Gabarito Retrátil e Feedback:**
  * Gabarito nativo acessível via tags `<details>` e `<summary>`.
  * Tabela completa de pontuação com cabeçalho (`thead`), corpo (`tbody`) e rodapé (`tfoot`).
  * Formulário de contato estruturado com `<fieldset>` e `<legend>` para envio de dúvidas e comentários.
